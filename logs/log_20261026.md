I skipped my recovery run yesterday due to the storm, so I felt pretty stiff on this one. I was also pretty cold when I set off - but at least it was dry!

The theme of the run was "struggling", specifically on framing struggling as a positive rather than a negative. If you are struggling then you are striving to achieve a goal in a resolute manner. It basically means you are a badass. There is no shame in being a badass, so there can be no shame in struggling.

Probably the only thing more badass than struggling is sharing your struggles and asking for help. So if you are struggling with something, being vulnerable enough to ask for help, or generous enough to offer it, then know that you are a BADASS.
