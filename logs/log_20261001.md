New shoes.

The theme for this run is definitely new shoes.

As part of the deal I made with myself for committing to this marathon, I bought some new shoes. These shoes are, basically, mental. Nike Vomero Premiums, if you don't mind. Mark the "premium" for me would you, please? Mark it for me. Running in them is like running on mini trampolines. They also add a couple of inches to my height, which does wonders for my self confidence. 

The run itself was fine. Pretty unremarkable. I had to run at that awkward 6/10 effort, which is always annoying (but in a good way). Also nice to have another run along #Roseburn path - I think it is going to get properly spooky as we mover deeper into autumn.
